# T041 — UI 접근을 DB·Store·업무 액션으로 통일

- 상태: 완료
- 생성: 2026-09-17
- 완료: 2026-09-17

## 배경

T040 이후 프로젝트 집계·현재 사용자 조회와 mutation 상태가 화면의 React Query에 남아 있다.
Query를 도메인 훅 뒤로 감추는 대신 서버 데이터는 DB 컬렉션, 실행 상태는 페이지/컴포넌트 Store가 소유하도록 한다.

## 작업 내용

- 프로젝트 서버 집계와 인증 사용자 데이터를 DB로 제공한다.
- UI의 React Query·tRPC 직접 접근을 제거한다. Query가 필요하면 컬렉션의 전송/캐시 구현 내부에만 둔다.
- 액션 실행 상태를 Store로 관리하고 기존 Form의 제출 상태를 재사용한다.
- SSR 복원·세션 종료·원격 변경 후 집계 갱신을 유지한다.
- 의존성 규칙과 회귀 테스트로 경계를 강제한다.

## 완료 기준

- [x] 화면이 DB/Store/업무 액션으로 데이터에 접근한다.
- [x] 로그인·로그아웃, 집계 갱신, SSR이 유지된다.
- [x] 타입 검사·경계 검사·관련 테스트를 통과한다.

## 대화 기록

> **사용자**: 남아 있는 쿼리를 모두 ui계층에서 없애고 싶은데

> **어시스턴트**: 화면에서 React Query와 API를 직접 참조하는 부분을 도메인 훅으로 옮기겠습니다. 조회와 액션의 실행 상태는 훅 내부에서 관리하고, 화면은 데이터와 업무 동작만 사용하도록 수정하겠습니다.

> **사용자**: 아니 단순히 옮기는게 아니라 스토어와 디비로 접근하게 하고싶어

> **어시스턴트**: 이해했습니다. Query를 훅 뒤에 숨기는 방식이 아니라, 화면은 DB로 서버 데이터를 구독하고 Store로 UI·액션 상태에 접근하게 하려는 뜻이군요. 남아 있는 집계·사용자 조회와 뮤테이션 상태를 그 기준으로 재설계하겠습니다.

## 작업 로그

- 2026-09-17: 기존 화면의 Query 사용과 데이터·인증·SSR 경계를 확인한다.

- 인증과 프로젝트 집계를 queryCollectionOptions 기반 실제 DB 컬렉션으로 옮긴다. Query는 컬렉션 내부 캐시에만 남긴다.
- 로그인/회원가입/로그아웃을 인증 도메인 액션으로 옮기고 화면은 DB live query, Store 또는 Form의 실행 상태를 사용한다.
- Router context에서 rpc/QueryClient를 제거하고 feature의 Query·전송 라이브러리 import를 의존성 검사로 금지한다.
- 기존 34개 테스트에 인증 격리·집계 재조회·SSR·Store 동시 실행 회귀 검증을 추가해 총 46개 테스트를 통과한다.
- 전체 워크스페이스 타입 검사, 의존성 검사, 웹 production 빌드, Biome 및 diff 검사를 통과한다.
- 실제 BFF+빌드 서버에서 오늘·업무 상세·프로젝트 상세·프로젝트 목록·설정 화면 모두 HTTP 200과 SSR 내용을 확인한다.
- 브라우저 E2E는 Chromium이 없어 미실행한다. Vitest의 종료 지연 경고는 T040에서도 확인된 환경 문제이며 테스트 프로세스는 0으로 종료한다.

### 후속 진행 안내 원문

> **어시스턴트**: 구조는 이렇게 바꾸겠습니다. 프로젝트 집계와 현재 사용자도 DB 컬렉션으로 읽고, 버튼의 실행 중·실패 상태는 Store가 관리합니다. Query는 DB 컬렉션 내부의 캐시·재조회에만 사용하고, 폼은 기존 Form의 제출 상태를 유지합니다. 화면에서 Query나 tRPC를 다시 직접 가져오지 못하도록 의존성 검사도 추가하겠습니다.

> **어시스턴트**: 화면의 Query 조회와 `useMutation`을 제거했습니다. 집계와 사용자 정보는 실제 DB 컬렉션으로 옮겼고, 액션의 대기·오류 상태는 Store가 소유하게 했습니다. 이제 로그인·로그아웃 시 데이터 격리, 집계 재조회, SSR 복원이 유지되는지 검증하겠습니다.

> **어시스턴트**: 타입 검사와 빌드는 통과했습니다. 추가 테스트에서는 로그인·로그아웃의 DB 반영, 종료된 세션의 늦은 응답 차단, 겹친 액션의 대기 상태, 집계 재조회와 하이드레이션을 확인하고 있습니다. 이어서 실제 서버로 오늘·상세·프로젝트·설정 화면의 SSR도 확인하겠습니다.
