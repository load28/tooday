## 배경

사용자가 "이 프로젝트에서 절대적으로 지켜야 하는 컨벤션"으로 지정: 커밋을 태스크
단위로 하고, 커밋 메시지에 태스크 번호를 넣어 태스크↔커밋을 이력에서 바로 잇는다.
기존 규칙은 한쪽(태스크 파일에 커밋 해시 기입)만 있었고 커밋에서 태스크로 가는
역방향 링크가 없었다.

## 작업 내용

- `docs/conventions/git-commits.md` 신설 — 규칙 정의:
  - 한 커밋 = 하나의 태스크 범위(태스크 혼합 금지, 한 태스크 다중 커밋은 허용).
  - 제목 끝 `(T0XX)`로 태스크 번호 명시(`git log --oneline`·`--grep` 추적).
  - 사용자 글로벌 규칙 유지: 영어 conventional 제목, 한국어 "한다"체 본문, AI attribution 금지.
- `CLAUDE.md` 컨벤션 인덱스에 한 줄 등록(절대 규칙 표시).
- `docs/tasks/index.md` 관리 규칙에 규칙 6 추가.
