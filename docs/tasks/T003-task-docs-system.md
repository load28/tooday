   인덱스가 각 파일을 참조해 상태 표시.
3. 각 태스크에 「대화 기록」 섹션 — 태스크를 만들었거나 방향을 바꾼 대화를
   원문으로 기록해 이후 세션이 문맥 없이도 착수 가능하게 한다.
4. `docs/refactoring-backlog.md` 삭제(내용은 태스크 파일들로 이관),
   CLAUDE.md 인덱스를 tasks/index.md로 교체하고 "모든 작업은 태스크 문서로
   시작한다" 지시 추가.
