> **관리 규칙** (index.md에 명시):
> 1. 작업은 무조건 태스크 파일로 시작 — 지시받으면 코드 만지기 전에 템플릿 복사
> 2. 하나의 태스크 = 하나의 파일 (`T###-슬러그.md`)
> 3. 문맥을 위해 해당 대화 전체를 「대화 기록」 섹션에 기록 — 사용자 발화는 원문
>    그대로, 진행 중 새 대화는 append
> 4. `대기 → 진행중 → 완료` 상태로 관리, 완료 시 완료일·커밋 해시 기입 + 인덱스 표
>    갱신, 완료 태스크는 삭제 안 함
> 5. 작업 로그에 검증 방법과 커밋을 남김
>
> **전환 내용**: 완료된 T001(feature 경계)·T002(FSD entities)·T003(이 체계 구축 자체)은
